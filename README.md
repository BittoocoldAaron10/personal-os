# Personal OS

Your AI-powered personal operating system. Built with Next.js, Supabase, and Google Gemini.

## Features

- 🎯 **Task Management (CRM)** - AI-classified tasks with voice input
- 📋 **Habit Tracking** - Daily habits with completion tracking
- 📔 **Journaling** - Voice & text entries with auto-summary
- 🍎 **Nutrition** - AI-powered calorie estimation
- 💪 **Health Metrics** - Track workout, study time, hobbies
- 🎯 **Goals** - Weekly, monthly, yearly goals
- 📅 **Calendar** - Manage your schedule
- 🎙️ **Voice Input** - Speak instead of type

## Tech Stack

- **Next.js 14** + React + TypeScript
- **Tailwind CSS** for styling
- **Supabase** for database & auth (FREE)
- **Google Gemini API** for AI (FREE - 1,500 req/day)
- **Web Speech API** for voice input (FREE)
- **Vercel** for hosting (FREE)
